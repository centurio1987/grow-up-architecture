## B. 추출 원장 양식

7장에서 정의한 추출 원장을 바로 쓸 수 있는 양식으로 정리했습니다. 원장은 세 부분으로 이루어져요. 어떤 자료를 받았는지 적는 **자료 목록**, 조각을 한 줄씩 적는 **원장 본문**, 답을 받기 전에 둔 **가정 목록**입니다.

### 자료 목록

출처 칸에 "메모 3"처럼 짧게 적으려면, 자료마다 이름을 먼저 정해 두어야 합니다.

| 자료 | 이름 | 형식 | 받은 날 | 준 사람 | 비고 |
| --- | --- | --- | --- | --- | --- |
| 메모 | 콘셉트 메모 | 문서(줄 번호 붙임) | 2026-11-10 | 운영 매니저 | 「틈」 예 |
|  |  |  |  |  |  |

### 원장 본문

```text
| ID | 칸 | 내용 | 출처 | 근거 | 이어지는 곳 |
| -- | -- | ---- | ---- | ---- | ----------- |
|    |    |      |      |      |             |
```

| 열 | 쓰는 법 |
| --- | --- |
| ID | 칸 머리글자 소문자 + 번호(t1, f3, v2, c1, r2, q4). 한번 붙인 번호는 바꾸지 않음 |
| 칸 | T·F·V·C·R·Q 가운데 하나 |
| 내용 | 아래 칸별 규칙에 맞는 문장 꼴 |
| 출처 | 자료 이름 + 위치(쪽·줄·시트·칸·발화 날짜와 발화자) |
| 근거 | 관찰·진술·확인 가운데 하나. Q 칸은 비움 |
| 이어지는 곳 | 설계한 뒤 채움. 개념의 F·R·D, 외부 V, 계약 O·E, 내부 결정 번호 |

### 칸별 작성 규칙

| 칸 | 문장 꼴 | 적는 것 | 적지 않는 것 |
| --- | --- | --- | --- |
| T 용어 | "○○란 ~이다. 동의어: ○○. 헷갈리는 말: ○○" | 낱말의 뜻, 동의어, 혼동어, 씨앗의 오류로 보이는 표기와 그 해석 | 씨앗을 고쳐 쓴 문장 |
| F 사실 | "○○가 ○○를 ○○에 ~했다" (구체적인 값) | 구체적인 사실 하나. 값을 모르면 ○로 두고 나중에 채움 | 일반화한 규칙(R 칸으로), 화면 모양(V 칸으로) |
| V 보기 요구 | "○○(이용자)는 ○○를 ○○하려고 본다" | 누가, 무엇을, 무엇을 하려고. 순서·묶음·시점이 언급되면 함께 | 화면 색·배치 |
| C 연산 | "○○(행위자)가 ○○를 ~한다, 얼마나 자주" | 누가 무엇을 바꾸는가, 빈도 | 빈도를 모르면 지어내지 말고 Q로 |
| R 규칙 | "○○는 언제나 ~이다 / ○○에서 ○○로만 바뀐다" | 늘 참이어야 하는 것, 허용되는 변화 | 추측(Q 칸으로) |
| Q 미결 질문 | "~인가? (누구에게 물을지)" | 모르는 것, 씨앗끼리 어긋나는 것, 해석이 둘 이상인 것 | 답을 지어낸 것 |

한 줄에 둘을 적지 않습니다. 문장에 "~이고", "그리고"가 있으면 둘로 나눌 수 있는지 먼저 봐요(8장의 "그리고" 검사).

### 근거 수준

| 수준 | 뜻 | 예 | 규칙(R)을 다루는 법 |
| --- | --- | --- | --- |
| 관찰 | 자료에서 보였다 | 예약 기록 2천 건에서 겹침이 없었다 | 규칙으로 쓰지 않음. 감시 질의로 지켜보고 진술·확인을 구함 |
| 진술 | 누군가 그렇다고 말했다 | 매니저: 겹치게는 못 잡아요 | 응용에서 경고로 시작. Q에 "확인 필요" |
| 확인 | 책임자가 규칙으로 승인했다 | 운영 책임자가 승인(회의록 날짜) | DB 제약이나 계약의 사전조건으로 강하게 지킴 |

근거 수준은 올라갈 수 있습니다. 관찰을 들고 담당자에게 물어 진술을 얻고, 진술을 들고 책임자에게 가서 확인을 얻어요. 올린 날짜와 근거를 원장 줄에 덧붙입니다.

### 가정 목록

답을 받기 전에 설계를 진행해야 할 때 씁니다. 가정은 원장의 q를 지우지 않고 그대로 둔 채 따로 적어요(13장).

| 가정 | 걸린 질문 | 가정한 답 | 답이 다르면 바뀌는 곳 | 누구에게 언제까지 |
| --- | --- | --- | --- | --- |
| a1 | q4 등급이 달 중간에 바뀌면? | 월말 기준 등급 | V3 무료 분, 청구 질의. 월초 기준이면 M07 청구 0원 → 21,000원 | 회계팀, 다음 청구 전 |
|  |  |  |  |  |

### 「틈」의 원장 몇 줄

7장에서 콘셉트 메모를 옮긴 원장의 일부입니다. 설계를 마친 뒤 "이어지는 곳" 칸을 채운 모습이에요.

| ID | 칸 | 내용 | 출처 | 근거 | 이어지는 곳 |
| --- | --- | --- | --- | --- | --- |
| t2 | T | 노쇼: 예약하고 오지 않은 경우. "예약 안 하고 안 오는"은 "예약하고 안 오는"의 잘못으로 보임 | 메모 7 | 진술 | F7 상태 값 no_show |
| f1 | F | 회원 M07이 회의실 R1을 11-17 10:00~11:30에 예약했다 | 메모 1 | 진술 | F4·F5·F6·F7 |
| v1 | V | 데스크는 오늘 예약을 일정표로 본다(아침마다 출력) | 메모 5 | 진술 | V2 |
