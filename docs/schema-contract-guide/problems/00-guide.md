# 제5부 실습

## 실습 안내

제5부에는 문제 15개와 풀이가 있습니다. 본문에서는 「틈」의 회의실 예약 하나로 방법을 보였다면, 여기서는 도메인과 씨앗 형식을 바꿔 가며 같은 방법을 손으로 해 봐요. 도서관, 동물병원, 공유 자전거, 정비소, 꽃집, 철물점처럼 서로 다른 도메인을 골랐고, 「틈」은 일부러 넣지 않았습니다.

### 문제 배치

어떤 문제가 어느 씨앗 형식과 어느 장에 이어지는지 먼저 표로 보여 드릴게요. 난이도는 하(한 층만), 중(두세 층), 상(네 층 전부와 검증)으로 적었습니다.

| 문제 | 도메인 | 씨앗 형식 | 중심 층 | 난이도 | 연결 장 |
| --- | --- | --- | --- | --- | --- |
| P01 | 여러 도메인 | 문장 15개 분류 | 넷의 경계 | 하 | 1~6 |
| P02 | 작은 도서관 상호대차 | 서사 시나리오 | 개념·외부 | 중 | 8, 9, 15 |
| P03 | 동물병원 진료 예약 | 유스케이스 | 계약·개념 | 중 | 11, 16 |
| P04 | 공유 자전거 대여 | 사용자 스토리와 인수 조건 | 관점 통합 | 중 | 10, 16 |
| P05 | 온라인 서점 쿠폰 | Gherkin과 Examples 표 | 개념 제약 | 중 | 8, 17 |
| P06 | 온라인 강의 수강 신청 | 이벤트 스토밍 보드 | 네 층 | 상 | 18 |
| P07 | 스마트 온실 경보 | EARS 요구사항 | 계약·내부 | 중 | 11, 12, 19 |
| P08 | 동네 학원 | 영수증 양식과 출석부 | 상향식 개념 | 중 | 20 |
| P09 | 자동차 정비소 | 세 부서의 관점 | 관점 통합 | 상 | 10 |
| P10 | 동네 꽃집 | 메신저 주문 대화 | 원장·질문 | 중 | 21, 22 |
| P11 | 동아리 회비 장부 | 스프레드시트 | 구조 복원·정규화 | 중 | 23 |
| P12 | 택배 배송 기록 | CSV 덤프 | 프로파일링 | 상 | 24 |
| P13 | 운동 기록 앱 | 버전이 섞인 JSON 로그 | 스키마 추론·계약 진화 | 상 | 25 |
| P14 | 철물점 재고 | 오래된 DB | 역공학·실제 계약 | 상 | 26 |
| P15 | 농산물 꾸러미 정기 배송 | 콘셉트 문서 + 농부 메모 + 주문 엑셀 | 종합 | 상 | 전체 |

P01은 본문 제1부를 읽은 직후에 풀 수 있고, P02~P08은 제3부, P10~P14는 제4부의 해당 장과 짝을 이룹니다. P09와 P15는 특정 장 하나가 아니라 여러 장을 함께 써야 해요.

### 문제 하나의 생김새

모든 문제가 같은 골격을 씁니다. 순서를 알아 두면 어디까지 읽고 손을 움직여야 하는지 헷갈리지 않아요.

```text
## Pnn 제목 — 씨앗 형식
  난이도 · 씨앗 · 중심 산출물 · 연결 장 (표 한 줄)
  ### 상황           누가, 무엇을 하려고 이 자료를 가져왔는가
  ### 주어진 자료      씨앗 그대로. 고쳐 쓰지 않은 원본
  ### 과제           번호 붙은 과제. 과제마다 내야 할 산출물
  ### 실마리          막혔을 때만 읽는 힌트
  ### 풀이           과제 번호마다 #### 소제목
  #### 다른 답이 가능한 곳
  #### 흔한 실수
  #### 채점 기준
```

**주어진 자료**는 일부러 손보지 않았습니다. 오타, 모순, 빠진 정보가 그대로 들어 있어요. 실제 씨앗이 그렇기 때문입니다. 자료를 고쳐 쓰고 싶어지면, 고치지 말고 원장에 t나 q로 남기세요. 7장에서 본 대로 원장은 씨앗을 옮겨 적는 곳이지 고쳐 쓰는 곳이 아닙니다.

**풀이**는 과제 바로 뒤에 있습니다. 풀기 전에 풀이를 읽지 않도록, 과제를 다 읽고 나면 종이나 편집기를 열어 자기 답을 먼저 적은 뒤 내려가세요.

### 과제의 종류

과제는 여섯 종류로 나뉩니다. 문제마다 이 가운데 몇 개를 고르고, 과제 문장 끝에 어느 장의 표기로 내야 하는지 적어 두었어요.

| 과제 종류 | 내는 것 | 표기를 보여 준 장 |
| --- | --- | --- |
| 원장 | t·f·v·c·r·q 줄, 출처, 근거 수준 | 7장 |
| 개념 | 개체·값·사실 유형·제약·파생 규칙 | 2장, 8장 |
| 외부 | 다섯 항목(이용자·내용·모양·파생 규칙·갱신 의미)과 열마다 `←` | 3장, 9장 |
| 계약 | 다섯 겹(구조·의미·행위·품질·진화), 실패표, 진화 정책 | 5장, 11장 |
| 내부 | 표·키·제약 DDL, 작업 부하 표, 결정 기록, 보장 위치표 | 4장, 12장 |
| 검증 | 추적표, 인구 왕복의 기대값, 반례 시험 | 13장 |

산출물은 본문과 같은 번호 체계로 적습니다. 원장 줄은 소문자(`f3`, `q2`), 개념 스키마 요소는 대문자(`F1`, `R3`, `D1`), 외부 스키마는 `V`, 계약은 `O`(연산)와 `E`(이벤트), 작업 부하는 `W`예요. 다만 문제마다 번호를 새로 씁니다. P02의 `F1`과 본문 「틈」의 `F1`은 서로 다른 사실 유형입니다.

### 채점 방법

풀이 끝의 **채점 기준** 표는 과제마다 반드시 들어가야 할 것과 있으면 더 좋은 것을 나눠 적었습니다.

| 열 | 뜻 |
| --- | --- |
| 항목 | 확인할 내용 하나 |
| 필수 / 권장 | 필수가 빠지면 그 과제는 미흡. 권장은 더 나은 답의 표시 |
| 확인 방법 | 무엇을 보고 판단하는가(원장의 줄, 스키마의 제약, 계산 값 등) |

점수를 매기고 싶다면 이렇게 하면 됩니다. 필수 항목 하나에 2점, 권장 항목 하나에 1점을 주고, 과제별로 필수를 모두 채웠을 때만 그 과제를 통과로 봅니다. 필수를 다 채우지 못했는데 권장 점수가 높은 답은 겉모습은 좋지만 빠진 곳이 있는 답이에요.

여기서 헷갈리기 쉬운 포인트는 풀이와 **똑같아야** 맞는다고 생각하는 것입니다. 풀이는 하나의 답이에요. 각 문제의 "다른 답이 가능한 곳"에 다른 선택이 정당한 자리를 적어 두었습니다. 자기 답이 풀이와 다르다면, 그 차이가 "다른 답이 가능한 곳"에 있는지, 아니면 "흔한 실수"에 있는지 먼저 보세요. 앞이라면 근거를 적었는지만 확인하면 되고, 뒤라면 고칩니다.

> 풀이와 같은지보다, 다른 곳마다 근거를 댈 수 있는지를 봅니다.

부분 점수에 대해 하나 더 덧붙일게요. 답을 모르는 곳을 지어내 채운 답보다, q로 남기고 "누구에게 무엇을 물을지" 적은 답을 더 높게 칩니다. 채점 기준 표에도 "미결 질문을 남겼는가"가 필수 항목으로 들어 있는 문제가 많아요.

### 권하는 풀이 순서

처음이라면 아래 순서를 권합니다. 앞 문제에서 쓴 기술을 뒤 문제가 다시 쓰도록 배치했어요.

```text
1. P01            넷의 경계를 먼저 손에 익힘
2. P02 → P05      원장 → 개념 → 외부의 기본 흐름 (P05 에서 인구 검사)
3. P03 → P07      계약 쓰기 (P07 에서 내부 스키마까지)
4. P04 → P09      관점 통합 (P09 는 충돌 종류를 모두 다룸)
5. P06 · P08      네 층을 한 번에, 상향식 설계
6. P10 → P14      거친 자료 (P12 부터 스크립트 사용)
7. P15            전부 합친 종합 문제
```

시간이 부족하다면 P01, P05, P09, P12, P15 다섯 문제만 풀어도 이 가이드의 방법을 대부분 거치게 됩니다.

### 스스로 점검하기

1. 어떤 문제의 주어진 자료에 "회원은 한 달에 두 번까지 예약할 수 있다(단 VIP는 제외)"와 "VIP도 세 번 넘게는 안 된다"가 함께 적혀 있습니다. 이 자료를 어떻게 다뤄야 할까요?
2. 자기 답의 개념 스키마에 풀이에 없는 제약이 하나 더 있습니다. 채점할 때 무엇을 확인해야 할까요?

#### 풀이

1. 두 문장은 서로 어긋날 수 있습니다(VIP는 제한이 없는지, 세 번까지인지). 자료를 고치지 말고, 원장에 두 문장을 각각 r로 옮긴 뒤 q를 하나 남깁니다. 예: `q1 · VIP의 월 예약 한도는 없는가, 3회인가? · 자료 2쪽 두 문장`. 설계를 계속해야 한다면 한쪽을 가정으로 두고, 가정이 틀렸을 때 바뀌는 곳(제약 하나, 계약의 사전조건 하나)을 적습니다.
2. 그 제약에 원장의 근거(r 줄과 출처)가 있는지 봅니다. 근거가 있다면 풀이가 놓친 것이거나 다른 답이 가능한 곳이고, 근거가 없다면 10장 품질 점검의 적절성 문제(근거 없는 요소)입니다. 근거 수준이 관찰이나 진술뿐인데 DB 제약으로 강하게 걸었다면, 7장의 근거 수준 표에 맞지 않으므로 그것도 고칩니다.
