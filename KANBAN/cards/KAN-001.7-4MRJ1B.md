# KAN-001.7-4MRJ1B — 추가 패턴 4편 집필 — Dependency Injection · Temporal Property · Null Object · Specification

## 전략
<!-- 왜 이 접근인가 · 제약 · 버린 대안. 사람이 자유롭게 편집한다. -->
**출처**: `KAN-001.1-P5N9NF` 검토서 1번 항목 승인(2026-09-27). 원문은 카드의 `원문` 블록에 있다. 조사 근거는 `pattern-guide/research/candidates.md`.

**왜 맨 뒤인가.** 검토가 승인한 순서가 「기준선은 파일럿 회고 직후, 나머지 넷은 인덱스 정리 카드 뒤」다. 넷이 기존 33편의 비교 절에 등장하므로 33편이 먼저 서 있어야 비교 대상을 가리킬 수 있고, 인덱스·검증 숫자를 두 번 고치지 않는다. 다섯 후보 중 DDD 용어 기준선은 이 카드가 아니라 `KAN-001.3` S8 에서 참고 문서 `ddd-tactical-terms` 로 이미 섰다.

**트랙 배정 — 착수 때 확정한다.** 조사 기준 배정은 이렇고, 넷 모두 GoF 원서 밖이라 spec 선택에 판단이 든다.

- Dependency Injection — 갈래 「GoF 밖 설계」, 조사가 `gof-guide` 를 지목
- Null Object — 갈래 「GoF 밖 설계」, spec 미명시
- Specification — 갈래 「GoF 밖 설계」, 조사가 `gof-guide` 를 지목
- Temporal Property — 갈래 「분석 패턴」, `analysis-guide` 로 보이나 명시 없음

그 배정대로면 GoF 23 → 26, 분석 10 → 11, 합계 37편이다. **spec 이 정해져야 완료 기준의 숫자가 정해진다** — 착수 전에 네 편의 조사 절을 다시 읽고 확정한 뒤 이 절에 적는다.

**PG27 근거 문제를 먼저 본다.** 명세 PG27 은 `[필수]` 조건마다 원전 근거 괄호를 요구하고, 인정하는 원전을 GoF 원서·Fowler Analysis Patterns·저자 공개 보충 자료(eaaDev·apsupp)·DDD 원전(Evans·Vernon)으로 열거한다. 넷의 원전은 그 목록과 이렇게 만난다 — Specification 은 Evans·Fowler 공동 논문, Temporal Property 는 eaaDev, Dependency Injection 은 Fowler bliki, Null Object 는 Woolf 의 PLoP 논문이다. **Fowler bliki 와 Woolf 논문이 열거에 없다** — 착수 전에 PG27 열거를 넓힐지, 넷 중 일부를 다른 근거로 세울지 정해야 한다. 안 정하면 집필 중에 기계 검사가 막는다.

**배치**: 편당 work 하나로 넷이다. `batch_size_works` 가 2 이므로 2배치가 기본이고, 착수 시점에 배치 문서를 만든다.


**★ 집필 전에 [KAN-001.4-BJT8JD 의 「반복해서 걸리는 자리」](KAN-001.4-BJT8JD.md#전략) 를 읽는다.** GoF 22편을 쓰며 **열세 가지**가 쌓였다 — 진단 인용 · 진단 원인을 따로 확인 · 재현 절차의 범위(줄을 지우면 뒤 번호가 당겨진다) · 원전 귀속(장·절 이름까지) · 성립 요건과 구현 쟁점의 분리 · 노트의 항목 수를 그대로 받지 않기 · `Skill` 도구 호출 금지 · `--run` 의 `.strip()` 함정 · **근거 괄호가 조건 문면을 실제로 받치는지 조각 단위로** · **규칙끼리의 모순은 문장들 사이에 있다(교차 판정 표)** · 원전 항목 수는 절 경계 태그로 센다 · 조건 문면을 고치면 그것을 쓰는 자리를 전부 따라 고친다 · 채점자에게 앞 라운드 사본 보존을 요구한다. **뒤 넷은 배치8~11 에서 실제로 1라운드 FAIL 을 냈다.** 워커·채점자 입력에 그대로 넣는다.

work 하나 = 가이드 한 편. 순서는 원전 근거가 확실한 쪽부터다 — PG27 열거 문제(전략 절)가 가장 늦게 걸리는 편을 뒤에 둔다.

- [ ] `S1` Specification 재집필 — 완료 기준: 트랙 확정 → `resolve --frozen` 통과 → authoring-write PASS(라운드 ≤ 3) → `check-guides --all --compile --run` 0 → `gate-results.jsonl` 1줄 + HTML 렌더 + 도식 검사. 원전은 Evans·Fowler 공동 논문(PG27 열거 안)

- [ ] `S3` Dependency Injection 재집필 — S1 기준. 원전이 Fowler bliki 라 **PG27 열거 확장이 선행**한다
- [ ] `S4` Null Object 재집필 — S1 기준. 원전이 Woolf PLoP 논문이라 **PG27 열거 확장이 선행**한다. 기존 33편의 비교 절에서 이 패턴을 가리키는 자리가 있으면 상호 링크를 건다
