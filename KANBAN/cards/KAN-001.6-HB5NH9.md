# KAN-001.6-HB5NH9 — 인덱스·stale 정리·최종 검증

## 전략
<!-- 왜 이 접근인가 · 제약 · 버린 대안. 사람이 자유롭게 편집한다. -->
**왜 마지막 카드인가.** 링크가 깨진 인덱스(`PATTERNS.md`의 GoF 링크 23/23이 `pattern-guide/<name>.md`를 가리키는데 실제는 `pattern-guide/design-pattern-guide/<name>.md`)는 재집필을 보이지 않게 하고, 검증 없는 완료는 승인할 근거가 없다. 33편이 다 선 뒤에 한 번에 맞춘다.

**인덱스 3종**: `PATTERNS.md`(GoF 23 링크 + DDD 10 추가) · `README.md`("패턴 가이드 문서" 절 — 현재 구조와 불일치, DDD 미언급, Cowork 문장) · `pattern-guide/ddd-analysis-pattern-guide/README.md`. HTML 33편은 여기서 `render-guides.py --all`로 일괄 렌더하고 인덱스 HTML도 함께 낸다.

**stale 잔여 처분**: 루트 `디자인 패턴 가이드 템플릿 작성을 위한 참조 문서.md`(옛 골격 메모 — 폐기 또는 이력 표기) · README의 "4언어 비교 학습 작업 공간" 서술과 언어별 파일명 컨벤션 표 · `.agents/skills` diff. **4언어 실행 하니스(`Makefile` · `python/` · `java/` · `typescript/` · `rust/`)와 `analysis/`의 처분은 기본값 유지 + README 표 개정**이다 — 가이드는 세 언어(Python 없음)라 README가 말하는 것과 어긋나므로 서술만 맞춘다. 삭제를 원하면 별도 카드로 분리한다(늦은 범위 확장 방지).

**최종 검증과 검토서**: 루트 카드 「검증」 절의 결정론적 명령 전부를 돌려 0을 확인하고 `review-init`으로 검토서 정본을 세운다(판단 항목은 루트 「검증」 절의 사람 판정 7건). 검토 대상 base는 카드 등록이 아니라 **착수 직전 커밋**이다.

      - **이후 배치에서 나오는 같은 성격의 제안을 여기에 계속 모은다.** 워커 보고의 「다음 patch 감」·「비차단」·「다음 판본용」이 그 표시다
